BRISAS DE MALVÍN — WEB ESTÁTICA PARA GITHUB PAGES

1. Creá un repositorio público llamado brisasdemalvin en tu cuenta de GitHub.
2. Descomprimí este ZIP. Subí el CONTENIDO de la carpeta brisas-de-malvin a la raíz del repositorio. index.html debe quedar visible en la raíz, junto a styles.css, script.js, privacidad.html y assets.
3. En Settings > Pages elegí Deploy from a branch, main, /(root) y Save.
4. GitHub indicará la URL de la web una vez publicada.
5. Primero revisá esa dirección desde computadora y celular. La web actual permanece activa.
6. El dominio www.brisasdemalvin.com se conecta después de aprobar la nueva versión. No se incluye CNAME ni se han modificado DNS.
